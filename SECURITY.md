# Security Policy

## Secrets interdits dans ce dépôt

Ne jamais publier :

- clés API VirusTotal ;
- URLs complètes de Webhook Shuffle ;
- URLs de Webhook Discord ;
- tokens d'authentification ;
- mots de passe ;
- identifiants de connexion.

Utiliser des variables d'environnement, secrets locaux ou mécanismes de gestion de secrets.

## Laboratoire

Les simulations décrites dans ce dépôt sont destinées exclusivement à un environnement de laboratoire autorisé et isolé.
